SECUREDLANDING v3.0 — MESSAGES COUNTEROFFER RESPONSE

1. Copy these files into the matching project folders:

   src/components/AdminLoanReviewActions.tsx
   src/components/MessageCenter.tsx

2. In Supabase, open SQL Editor and run:

   supabase/migrations/20260729_messages_counteroffer_response.sql

3. Commit and deploy the project.

4. Test with two accounts:
   - Admin sends a revised offer.
   - Borrower opens Messages.
   - Borrower opens the loan conversation.
   - Borrower accepts, declines, or sends a question.

IMPORTANT
- Run the SQL migration before testing the Accept/Decline buttons.
- This patch expects loan_applications.id and messages.loan_application_id
  to use bigint-compatible loan IDs.
