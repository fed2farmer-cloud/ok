INSTALL ORDER
1. Back up the database and repository.
2. Review and run:
   supabase/migrations/20260725_v31_electronic_signatures.sql
3. Copy the files under src/ into the matching repository folders.
4. Add the route shown in docs/APP_ROUTE.tsx to src/App.tsx.
5. Add the Closing Center link described in docs/CLOSING_CENTER_INTEGRATION.md.
6. Connect admin authorization before calling request_borrower_signature.
7. Run npm run build.
8. Test in a non-production environment.
9. Complete the production controls in docs/PRODUCTION_SECURITY.md.

IMPORTANT
This is a targeted upgrade package, not the complete SecuredLanding repository.
The signature UI is functional, but server-side PDF hashing, finalized signed
PDF generation, IP capture, notary handling, and legal review remain required
before treating the workflow as production-ready for recorded loan documents.
