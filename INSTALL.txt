INSTALL
1. Back up the existing repository.
2. Replace src/pages/InvestorMarketplace.tsx.
3. Add src/lib/pendingSplitInvestment.ts.
4. Read docs/SPLIT_PAYMENT_INTEGRATION.md before enabling live split checkout.
5. Update the NMI payment success handler to finalize the split payment on a trusted server.
6. Run npm run build.
7. Commit and deploy.

The marketplace source has an explicit default export and contains no Markdown fences.

IMPORTANT
The marketplace UI and routing are complete in this ZIP. The trusted server-side
NMI verification/finalization step must be connected to your existing payment
backend before split payments are used with real money.
