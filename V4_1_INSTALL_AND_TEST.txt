SecuredLanding v4.1 Install + Test

1) Upload the ZIP contents to the GitHub repo, preserving original filenames and paths.
2) In Supabase SQL Editor, run:
   supabase/migrations/20260811_v4_servicing_payment_settlement_fix.sql
3) Then run:
   supabase/VERIFY_V4_SERVICING_PAYMENT_FIX.sql
4) In Vercel, confirm these environment keys are present:
   VITE_SUPABASE_URL
   VITE_SUPABASE_ANON_KEY
5) Deploy from GitHub.
6) Visit these routes after deployment:
   /admin/servicing
   /repayments
   /secondary-market

- loan_payment_schedule has 60 rows.
- One schedule row is paid.
