SecuredLanding v4.4.8 - Public Certificate Preview Fix
Date: 2026-09-10

ISSUE FIXED
An authenticated prospective buyer could select a certificate on the Secondary
Market but then see "Certificate not found." The certificate page queried the
owner-protected investments table and treated an RLS-hidden row as missing.

CHANGED FILE
src/pages/InvestmentCertificateDetails.tsx

NEW BEHAVIOR
1. Current owners continue to receive the full private certificate view.
2. Prospective buyers receive a limited public preview sourced from
   secondary_market_open_v2.
3. Private owner IDs, certificate UUID and ownership history remain protected.
4. The public preview provides Review Loan Performance and Buy Certificate
   actions using the correct loan number and listing UUID.
5. Removed or sold listings return "Certificate not found or no longer listed."

DATABASE INSTALL
No SQL migration is required. The fix uses the existing
secondary_market_open_v2 view.

BUILD VERIFICATION
npm run build: PASS
