# Admin Revision Workflow

Add a **Request Revision** button to each pending application.

Workflow:
1. Select missing items.
2. Enter a message.
3. Send request.
4. Status -> `Revision Requested`.
5. Borrower updates application.
6. Borrower clicks `Submit for Review`.
7. Status -> `Resubmitted for Review`.
8. Admin reviews again.

Suggested checklist:
- Property address
- County
- State
- APN
- Acreage
- Property valuation
- Ownership documents
- Government ID
- Borrower video
- Loan purpose
- Other
